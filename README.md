# SANA AI // Vision Analytics Frontend

Современный веб-интерфейс на **React + Vite + TypeScript** для компьютерного зрения и автоматизированного выявления нарушений кассовой дисциплины (KassaCV).

---

## 🚀 Возможности системы

1. **Интерактивный видеомонитор кассовой зоны**:
   - Синхронизированный таймлайн с маркерами нарушений (инцидентов).
   - Мгновенный переход к моменту нарушения по клику на таймкод или маркер.
   - Скорости воспроизведения (0.5x, 1x, 1.5x, 2x), покадровая перемотка (±2 сек), HUD-оверлей с детекцией.
2. **Анализ нарушений и вердиктов**:
   - Статусы: **Выявлены нарушения** / **Нарушений не выявлено**.
   - Оценка уверенности модели (AI Confidence, 0–100%).
   - Юридические основания (Налоговый кодекс РК ст. 166, Правила безопасности п. 4.2, Типовые правила п. 12).
3. **Доказательная база (Evidence Inspector)**:
   - Галерея кадров с bounding boxes в высоком разрешении.
   - Полноэкранный просмотр, покадровое переключение и скачивание скриншотов с фиксацией.
4. **Визуализация нейросетевого пайплайна**:
   - 6 этапов: Ingestion ➔ Sampling ➔ YOLOv8 / Pose ➔ Tracking ➔ VLM Verification ➔ Rule Aggregator.
5. **Каталог норм и правил**:
   - Встроенный справочник нарушений (R-01, R-02, R-03) с прямыми ссылками на первоисточники законодательства РК (Adilet.zan.kz).
6. **Официальный акт аудита (PDF / JSON)**:
   - Генерация печатного акта ревизии с подписью контролера и экспорт данных в JSON.
7. **Демо-режим и подключение к живому FastAPI бэкенду**:
   - Встроенные готовые тест-кейсы для демонстрации без запуска бэкенда.
   - Настройка URL (`http://localhost:8000`) и `X-API-Key` в модальном окне параметров.

## 🛠 Запуск проекта

### 1. Установка зависимостей
```bash
npm install
```

### 2. Запуск в режиме разработки
```bash
npm run dev
```
Приложение откроется на [http://localhost:3000](http://localhost:3000).

### 3. Сборка для продакшена
```bash
npm run build
```

## 📁 Структура проекта

```
src/
├── components/
│   ├── Header.tsx             # Шапка, статус подключения к API, счетчики
│   ├── VideoPlayer.tsx        # Видеоплеер с маркерами инцидентов на таймлайне
│   ├── UploadZone.tsx         # Drag & Drop загрузчик и готовые демо-кейсы
│   ├── ViolationsList.tsx     # Карточки нарушений, таймкоды, юридические ссылки
│   ├── EvidenceViewer.tsx     # Модальное окно просмотра доказательной базы
│   ├── JobStatusTracker.tsx   # 6-этапный статус-трекер пайплайна
│   ├── RulesDrawer.tsx        # Справочник правил и статей законов
│   ├── SettingsModal.tsx      # Настройки URL бэкенда, API-ключа и демо-режима
│   ├── ReportModal.tsx        # Формирование официального акта аудита
│   └── HistoryList.tsx        # История недавних проверок с переключением
├── data/
│   ├── mockData.ts            # Готовые тестовые сценарии с кадрами детекции
│   └── rulesCatalog.ts        # Справочник правил R-01, R-02, R-03
├── services/
│   └── api.ts                 # Клиент API (upload, poll, health, fallback)
├── types/
│   └── api.ts                 # Контракты Pydantic-моделей бэкенда
├── index.css                  # Неоновая темная дизайн-система (Vanilla CSS)
└── App.tsx                    # Основной экран приложения
```
